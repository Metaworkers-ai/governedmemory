Use cases

One engine, aimed at the moments that matter

Every scenario below is the same underlying problem — an agent about to act on a memory it shouldn't trust. The core five have a full visual walkthrough; the industry deep-dives are grounded in documented real-world incidents.

Core scenarios

Flagship Stop agents acting on poisoned memory

An agent that can issue refunds or escalate an account is one injected instruction away from doing it for an attacker.

Read → Injection Prompt injection, caught on write

Untrusted email, scraped pages, and tool output are scored and tainted the moment they're stored.

Read → Isolation Cross-tenant data leaks

On a multi-tenant platform a single cross-tenant read is company-ending. The boundary lives in the query itself.

Read → Compliance Need-to-know retrieval

A memory collected for support shouldn't drive a marketing decision. Purpose is enforced at query time.

Read → Audit "What did the agent know?"

A hash-chained, append-only log answers the first question in every incident review — provably.

Read → Hygiene Memory dedup & supersede

Stop agents re-writing the same fact every session — and stop a stale fact from answering after it's corrected.
