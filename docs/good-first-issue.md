# Good first issues

These are intentionally small, independently reviewable contributions. Before
starting, check the issue tracker and Discord so two people do not duplicate
the same work.

Browse the repository's current [good first issue](https://github.com/Metaworkers-ai/governedmemory/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
label before choosing work. The list may be empty; do not assume an issue is
available until it is actually filed.

- Add a missing local-link test case to `scripts/check_docs_links.py`.
- Improve one Quickstart troubleshooting message and add a regression test.
- Add a copy-paste example for an existing REST or SDK route.
- Clarify one security limitation with a minimal synthetic reproduction.
- Add a unit test for an uncovered validation branch in `api/` or `sdk/python/`.
- Improve mobile or keyboard accessibility in one Next.js page.
- Verify a documented command on Windows PowerShell and update the support
  matrix with the exact result.

Good first issues must include a reproduction or acceptance check. Avoid filing
requests for unsupported framework integrations without a concrete API contract
and a maintainer willing to review it.
